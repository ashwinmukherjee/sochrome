# Third-party data, models, fonts and code

Generated by `npm run third-party` from `src/third-party.json` and `package-lock.json`. Edit those, never this file.

## Notes

- **gnomAD.** The name never appears in a product or feature name, and no gnomAD logo is used: credit only.
- **gnomAD.** No SpliceAI or Pangolin fields are carried (CC BY-NC 4.0).
- **ClinGen.** No ClinGen logo is used.
- **Risk figures quoted from papers.** CHECKED, not by a clinician: every figure P3 draws was checked against its source and newer studies on 2026-11-19 and approved for the proof of concept. Figures from clinic families say so in P3.
- **Claude.** Gene lines and condition names were drafted with a language model from UniProt and Mondo text, then reviewed. Nothing is generated at runtime, and the app calls no model or API.
- **Inter.** Stand-in for Suisse Intl, not in use: built in only when the typeface token is "standin".
- **Source Serif 4.** Stand-in for Suisse Works, not in use: built in only when the typeface token is "standin".
- **IBM Plex Mono.** Stand-in for Suisse Mono, not in use: built in only when the typeface token is "standin".
